Harvesting Crops for XP
========
### Features :
- Harvesting mature crops will now give the player XP
- Config file to tweak the amount of xp given
- You can choose between giving the xp directly to the player, or spawning experience orbs
- You can set a count ; so the player must harvest crops N times before triggering the XP effects
